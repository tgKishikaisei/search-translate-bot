# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue. Нажмите «Report a vulnerability» на вкладке **Security** или напишите мне в Telegram: [@BehruzAvezmatov](https://t.me/BehruzAvezmatov).

## Что сделано

- Текст из PDF и переводы отправляются обычным текстом без HTML, длина обрезается до лимита Telegram.
- Ссылки поиска строятся с кодированием запроса, текст пользователя не попадает в разметку.
- PDF читается в памяти (BytesIO), на диске файлы не остаются; токен берётся из `.env`.

GitHub Actions на каждый push запускает тесты, `pip-audit` и `gitleaks` по всей истории.
